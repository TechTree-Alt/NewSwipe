# Neumorphism 모드

설정 › 테마 맨 아래의 **모드**에서 **Neumorphism**을 고르면 키보드뿐 아니라 설정 화면·편집 화면·대화상자까지
바탕과 같은 색의 면이 부드럽게 솟아오르거나(왼쪽 위 밝은 그림자, 오른쪽 아래 어두운 그림자) 안으로 들어간 모양이 됩니다.
키보드는 `ui/Neu`, 앱 화면은 `ui/NeuUi`가 그립니다.

## 규칙

| 무엇 | 모양 |
|---|---|
| 바탕·카드 | 같은 색 (라이트 `#E6E8EC`, 다크 `#202125`). 카드는 큰 그림자로 솟아오른다 |
| 실행 버튼, 되돌리기, 대화상자 버튼, 기능 고르기 칩 | 솟아오르고, 누르는 동안 안으로 들어간다 |
| 선택 버튼 줄 (화면 모드·강조 색·모드 등) | 칸마다 솟아오르고, 고른 칸은 안으로 들어가 글씨가 강조색 |
| 스위치 | 안으로 들어간 홈에 솟아오른 밝은 손잡이, 켜지면 홈이 강조색으로 찬다 |
| 슬라이더 | 들어간 홈, 그 안의 강조색 막대, 솟아오른 손잡이와 가운데 강조색 점 |
| 입력란, 메뉴 아이콘, 고른 기능 줄 | 안으로 들어가 있다 |
| 머리글의 동그란 버튼 | 솟아오른 동그라미에 강조색 아이콘, 켜짐·누름은 들어간다 |
| 강조 색 동그라미 | 솟아오르고, 고른 색은 들어간 홈에 앉는다. 바탕에 묻히는 색(검정 등)은 옅은 테두리 |
| 라디오·체크 | 들어간 홈에 강조색 점·체크 |

- 들어간 홈은 바탕보다 조금 어둡게(다크 30%, 라이트 3.5%), 손잡이는 조금 밝게 칠한다. 다크 모드는 밝은 그림자가 약해(흰색 13%)
  같은 색만으로는 홈과 꺼진 스위치가 바탕에 묻히기 때문이다.
- 그림자는 면 밖으로 번진다. Android는 부모가 자식을 그 자식의 영역까지만 그리게 자르므로(clipChildren), 바로 위 부모만 끄면
  그 부모가 다시 자기 부모에게 잘려 그림자가 카드·줄 경계에서 잘린다. 부모의 안쪽 여백 선에서 자르는 clipToPadding도 따로 있어
  (설정 목록은 좌우 여백만 있어 카드의 좌우가 잘린다), `NeuUi.unclip`이 위로 올라가며 부모의 두 자르기를 모두 끄고,
  그림자가 다 들어가는 부모에서 멈춘다(스크롤 틀은 끄지 않는다). 배치가 바뀔 때마다 다시 본다.
  자르기를 끈 뒤에도 하위 설정을 펼치고 접는 동안 내용이 삐져나오지 않게, 움직이는 뷰 자신을 지금 높이로 자른다(`Ui.setVisibleAnimated`).
- 버튼·선택 칸 사이는 그림자 자리만큼 조금 더 띄운다. 설정 메뉴 카드는 테두리로 자르지 않는다(자르면 그림자가 사라진다).

## 성능

솟아오른 그림자는 모서리 반지름(과 그림자 크기)마다 작은 조각 하나만 한 번 구워 두고, 아홉 조각으로 나눠 면 크기에 맞게 늘려 붙인다.
카드가 크거나 많아도 그림자 비트맵은 모서리 크기 수만큼(수십 KB씩)뿐이다. 안으로 들어간 그림자는 흐린 굵은 선 하나로 그린다.
그림자가 잘리지 않게 하는 리스너는 뷰마다 하나만 붙인다 (모양을 다시 입혀도 쌓이지 않는다).
