# 한국어 사전 팩

앱에 들어가지 않는, 설정에서 가져오는 한국어 사전입니다 (설정 > 추천, 학습 및 완성 > 한국어 사전 > 사전 팩 가져오기).
앱은 인터넷을 쓰지 않으므로, 사용자는 이 파일을 브라우저로 받아 파일 고르기 창에서 고릅니다.

| 파일 | 내용 | 라이선스 |
|---|---|---|
| `ko-standard.zip` | 표준 사전: 단어 8만 개 + 단어 쌍 40만 개 (약 1.1MB). 다음 단어 예측과 앞 단어에 맞춘 추천을 쓴다 | CC BY 4.0 (`ko-standard-LICENSE.txt`) |

릴리스를 만들 때 `ko-standard.zip`을 GitHub 릴리스에 첨부하세요. 만드는 방법은 [BUILDING.md](../BUILDING.md)의
'한국어 사전과 사전 팩'에 있습니다.
