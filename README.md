# NewSwipe

NewSwipe는 가볍고 현대적이며 편안한 한글 입력 시스템입니다.
<br />
<br />

## 핵심 가치

### 가벼움 (Lightweight)

입력 시스템은 항상 백그라운드에서 상주하며 언제 어느 상황에서나 적절하게 반응해야 합니다.  
NewSwipe는 자원 소모를 최소화하여 빠르고 기민하게 반응합니다.  
View를 최소한으로 그리고 외부 라이브러리를 최소한으로 사용합니다.  
앱 크기는 1MB 미만, 램 점유율은 90MB 미만입니다 (안드로이드 16, 램 16GB 기기 기준).  

### 현대적 (Modern)

가볍고 최적화가 잘 되어 있는 앱이라고 해서 딱딱하고 불친절할 필요는 없습니다.  
NewSwipe는 최신 안드로이드 API와 기능을 적극적으로 사용해 트렌드를 따라갑니다.  
Material 3 Expressive에서 영감을 받은 UX를 사용하며, 다크 모드, Predictive Back Design, Emoji 18.0을 지원합니다.  
가벼움을 유지하면서도 현대적인 입력기의 다양한 편의 기능(클립보드, 단어 추천, 단어 학습)을 제공합니다.  

### 편안함 (Comfortable)

입력 시스템은 스마트폰에서 가장 많이 쓰는 앱 중 하나이며, 동시에 가장 개인적인 앱이기도 합니다.  
NewSwipe는 하나의 경험을 모두에게 강제하지 않고, 다양한 사용 방식을 가진 사용자를 위해 다양한 사용자화 기능을 제공합니다.  
자신에게 딱 맞는 편안한 입력을 위해, 단 하나뿐인 입력 시스템을 직접 만드세요.  
<br />
<br />

## 특징
- 기존 사용자들에게 친숙한 기본 단모음에 **밀어서 입력** 방식을 더하여 종성-초성 겹침 문제를 해결합니다.
- 쌍자음, 겹받침, 이중모음을 **밀어서 입력**하여 최소한의 움직임으로 빠르고 정확하게 입력합니다.
- 양손 사용에 최적화된 **NewSwipe 단모음** 배열을 사용해 보세요.
- 자음을 왼손, 모음을 오른손에 분리하는 **균형 레이아웃**으로 예측 가능하고 박자감 있게 입력하세요.
- 가로 상태나 큰 화면에서도 **양쪽으로 분리 기능**으로 편안하게 사용하세요.
- **기능 키 (?123·🌐·␣·↵·⇧·⌫)의 유무와 순서**를 마음대로 조정하세요.
- 모든 키를 길게 누를 때와 상하좌우로 밀 때 어떤 일이 일어날지를 **직접 사용자화**하세요.
- **한국어의 특수성을 고려**한 단어 추천, 자동 수정, 학습 기능을 통해 편안한 환경을 만듭니다.
- **도구 막대**에서 유용한 기능들을 편하게 사용할 수 있습니다.
- 강력한 **클립보드** 기능으로 복사된 내용들을 효율적으로 관리하세요.
- **이모지 창**에서 최신 이모지를 효율적으로 찾고 고정하세요.
- **한 손 모드**를 사용자화해 자신에게 맞는 위치와 크기로 편하게 한 손을 쓰세요.

## 한글 자판

설정 › 자판 레이아웃에서 두 가지 배열 중 고를 수 있습니다.

**단모음** · 친숙한 기본 단모음 배열
```
 ㅂ  ㅈ  ㄷ  ㄱ  ㅅ  ㅗ  ㅐ  ㅔ
 ㅁ  ㄴ  ㅇ  ㄹ  ㅎ  ㅓ  ㅏ  ㅣ
     ㅋ  ㅌ  ㅊ  ㅍ  ㅜ  ㅡ  ⌫
```

- 각 자음 키를 아래로 밀어 된소리 (ㅃ·ㅉ·ㄸ·ㄲ·ㅆ)를 입력합니다.
- 각 모음 키를 두 번 연속 누르거나 아래로 밀어 ㅣ계 이중모음 (ㅑ·ㅕ·ㅛ·ㅠ·ㅒ·ㅖ)을 입력합니다.

**NewSwipe 단모음** · 사용이 적은 거센소리 일부를 빼 키의 크기를 키운 새로운 단모음 키보드
```
 ㅂ  ㅈ  ㄷ  ㄱ  ㅗ  ㅐ  ㅔ
 ㅁ  ㄴ  ㅇ  ㄹ  ㅓ  ㅏ  ㅣ
 ㅍ  ㅋ  ㅎ  ㅅ  ㅜ  ㅡ  ⌫
```

- 사용량이 적은 거센소리 중 일부를 빼고, 자주 입력하는 ㅅ과 ㅎ을 손가락이 잘 닿는 곳으로 옮겼습니다.
- 각 자음 키를 오른쪽으로 밀어 거센소리 (ㅍ·ㅊ·ㅌ·ㅋ)를 입력합니다.
- 모음 배열은 기본 단모음과 같아 적응이 빠릅니다.

## 기능

| 기능 | 내용 |
|---|---|
| 밀어서 글자 입력 | 아래로 밀어 쌍자음·ㅣ계 이중모음, 모음을 위·왼쪽·오른쪽으로 밀어 조합형 이중모음 (기본: ㅜ←ㅝ ↑ㅟ →ㅞ, ㅗ←ㅘ ↑ㅚ →ㅙ, ㅡ↑ㅢ), 자음을 위·왼쪽·오른쪽으로 밀어 겹받침 (8열 단모음 기본: ㄹ↑ㄺ ←ㄻ →ㅀ, ㄴ↑ㄵ →ㄶ, ㄱ→ㄳ, ㅂ→ㅄ). NewSwipe 단모음은 ㅂ·ㅈ·ㄷ·ㄱ를 오른쪽으로 밀어 거센소리 ㅍ·ㅊ·ㅌ·ㅋ을 입력하므로 ㄱ·ㅂ의 오른쪽 겹받침은 쓰지 않습니다. 키·방향별 편집과 완전 사용자화 지원 |
| 자음 이중 탭 (선택) | 설정 › 입력 동작에서 켜면 기존 단모음처럼 ㄱㄱ→ㄲ. 두 탭 사이가 '쌍자음 인식 시간'(기본 200ms) 안일 때만 쌍자음이라 보통 속도로 친 '학교'는 그대로. 기본은 꺼짐 |
| 밀어서 기능 | 스페이스바 커서 이동(속도 조절)·언어 전환, ⌫ 밀어 단어·줄 지우기, 기호 키 밀어 이모지, 도구 막대·버튼 밀기, 문자 키 트랙패드 커서, 두 손가락 실행 취소/다시 실행. 기능키·도구 막대·키보드 밀기를 완전 사용자화 |
| 기능키 순서·유무 | 맨 아래 줄 키의 순서와 유무, Shift 키·⌫ 유무. 한글 자판의 Shift 자리에 탭·길게 누르기·밀기 기능을 정하는 Fn 키를 둘 수 있음 |
| 키 정렬 | 격자 정렬(기능키를 한글 키 폭에 맞춤), 색 정렬(Shift·⌫를 글자 키 색으로) |
| 자·모음 균형 레이아웃 | 자판을 가운데에서 반으로 나눠 왼쪽에 자음(8열 단모음은 5열, 7칸 배열은 4열), 오른쪽에 모음 3열 (자음·모음 폭·가로 위치 조절). 가로 모드 분리 키보드: 가로 모드에서만 따로 자음·모음으로 나누고 폭·위치도 세로와 별개 |
| 인식 범위 좁히기 | ⌫(위·왼쪽·아래)와 스페이스바(위) 가장자리를 이웃 키로 봐 오타를 줄임 (5~50%) |
| 단어 추천 | 한국어·영어 추천과 자동 수정, 입력한 단어 학습 (시크릿 모드 등 학습 금지 입력란에서는 학습하지 않음) |
| 영어 | QWERTY. Shift 한 번 = 한 글자, 빠르게 두 번 = 고정 (Shift가 켜진 상태에서도) |
| 길게 눌러 특수문자 | 키마다 편집 가능 (₩ $ € …, é ñ …) |
| 기호·숫자 자판 | `?123` 두 쪽, 숫자 입력란에서는 숫자 자판 |
| 이모지 | Emoji 18.0까지 전체와 피부색 변형, 한글·영어 검색, 최근·고정 이모지 |
| 도구 막대 | 클립보드·이모지·음성 입력·실행 취소·한 손 모드·설정·키보드 숨기기 버튼. 왼쪽·오른쪽 배치와 순서·유무를 바꿀 수 있음 |
| 한 손 모드 | 자판과 도구 막대를 줄여 왼쪽·오른쪽으로 모음 (자·모음 균형 레이아웃이어도 빈틈 없이). 반대편 빈 곳에 옮기기 화살표·끄기(확장) 아이콘. 도구 막대 버튼 탭으로 켜고 끄기, 좌우로 밀어 그쪽으로 켜기, 밀어서 기능 완전 사용자화의 '한 손 모드 (왼쪽·오른쪽)'. 설정 › 한 손 모드에서 미리보기를 보며 자판 폭·키 높이·세로 위치 조절 |
| 클립보드 | 텍스트와 이미지(최근 5개) 최근 30개, 24시간 뒤 자동 삭제, 고정 최대 10개. 민감 정보로 표시된 복사는 저장하지 않음 |
| 테마 | 시스템·라이트·다크, 강조 색 |
| 설정 가져오기·내보내기 | 설정 파일로 저장·불러오기. 학습 단어·이모지·클립보드를 담을 때 비밀번호로 암호화 가능 (AES-256-GCM, PBKDF2) |

## 개인정보

- 인터넷 권한이 없으므로 어떤 데이터도 외부로 보내지 않습니다.
- 학습한 단어와 클립보드 기록(텍스트·이미지)은 앱 전용 저장소에만 저장되며 시스템 백업에는 포함되지 않습니다(`allowBackup=false`).
  설정에서 저장을 끄거나 모두 지울 수 있습니다.
- 비밀번호·이메일 입력란과 앱이 학습하지 말라고 표시한 입력란(시크릿 모드 등)에서는 단어를 학습하지 않습니다.
- 설정 내보내기에서 학습한 단어·이모지·클립보드 기록(텍스트만)을 직접 고른 경우에만 백업 파일에 담기며,
  이때 비밀번호로 파일 전체를 암호화할 수 있습니다 (AES-256-GCM, 키는 PBKDF2-HMAC-SHA256으로 만듦).
